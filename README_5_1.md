# LiteWorkSuite Web 5.1

Versão web integrada ao TwoSix 5.1.

Recursos principais:
- Editor de texto, planilhas, apresentações, páginas web, templates, PDF e LiteMacro.
- Importação/exportação Office Open XML conforme limites documentados.
- Projetos persistentes em IndexedDB com até 10 versões.
- Exportação/importação de projeto `.lws`.
- Integração com TwoSix Drive quando executado dentro do TwoSix.
- PWA instalável e cache offline em HTTPS.
- File System Access API quando disponível, com fallback para download.
- VBA/VBProject, COM/OLE/ActiveX e Office Scripts não são executados.
