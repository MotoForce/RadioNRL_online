# LiteWorkSuite

Aplicação web multifuncional criada do zero.

## Incluído
- Editor de texto com preset ABNT inicial
- Planilha editável com fórmulas básicas
- Editor de apresentações
- Editor de página web com pré-visualização
- Templates de escritório
- Exportação via impressão para PDF
- Salvamento local no navegador
- Área de PDF e conversões preparada para evolução

## Limitações importantes
- Compatibilidade perfeita com DOCX/XLSX/PPTX/PDF não é tecnicamente garantida apenas com HTML/JS puro.
- Conversões com preservação integral de formatação exigem motores específicos (por exemplo, LibreOffice headless no backend, bibliotecas especializadas ou serviços dedicados).
- O preset ABNT é um ponto de partida e deve ser validado conforme a norma aplicável e exigências institucionais.
